## About Me

I'm **Lilian Ezeh**, a Cloud & DevOps Engineer and Fullstack Engineer based in Nigeria. I work across the full application lifecycle — from writing backend and frontend code to deploying and operating it in production.

My core focus is cloud infrastructure, containerization, Kubernetes, CI/CD, and Infrastructure as Code. I also build backend services and web applications, which gives me a practical, end-to-end view of how software moves from development to a running, reliable system.

**Focus areas:**
- Cloud & DevOps Engineering (AWS, Kubernetes, Terraform, CI/CD)
- Fullstack Engineering (Python/FastAPI, React/Next.js)
- Monitoring, logging & observability

📍 Nigeria · 📫 lilianezichi@gmail.com
